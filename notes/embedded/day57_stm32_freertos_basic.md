## 1. STM32 是什么

STM32 是一种常见的微控制器，也叫 MCU。

它可以理解为：

```text
小型单片机
嵌入式芯片
飞控板上的控制核心之一
```

STM32 常用于：

```text
无人机飞控板
机器人控制器
电机控制板
传感器采集板
工业控制设备
智能车
```

它不像普通电脑一样运行 Windows 或 Ubuntu，而是运行嵌入式程序，直接和硬件外设通信。

---

## 2. 为什么飞控需要 STM32

无人机真实飞行时，需要飞控板实时完成很多底层任务：

```text
读取 IMU
读取气压计
读取 GPS
处理遥控器输入
运行姿态控制
运行角速度控制
输出电机 PWM / DShot
监测电池状态
处理通信数据
```

这些任务要求：

```text
响应快
延迟低
稳定可靠
能直接控制硬件引脚
能在小型飞控板上运行
```

因此飞控板通常使用 STM32 这类嵌入式微控制器。

一句话理解：

```text
STM32 负责靠近硬件、实时性强、必须稳定执行的底层控制任务。
```

---

## 3. FreeRTOS 是什么

FreeRTOS 是一个小型实时操作系统。

RTOS 的全称是：

```text
Real-Time Operating System
实时操作系统
```

FreeRTOS 常用于单片机和嵌入式系统。

它的作用是把复杂程序拆成多个任务，并让这些任务按照优先级和时间要求运行。

例如飞控中可以有：

```text
IMU 读取任务
姿态估计任务
控制器任务
电机输出任务
通信任务
日志任务
安全检查任务
```

---

## 4. 为什么需要 RTOS

如果没有 RTOS，程序可能写成一个大的 while 循环：

```c
while (1) {
    read_imu();
    estimate_attitude();
    run_controller();
    output_motor();
    communicate();
}
```

这种方式简单，但当系统复杂后会有问题：

```text
所有任务都排队执行
一个函数卡住会影响后面所有任务
不同任务频率不好管理
任务优先级不好管理
代码结构容易混乱
```

使用 FreeRTOS 后，可以把不同功能拆成多个任务，由调度器统一管理。

## 5. Task 任务

Task 是 FreeRTOS 中的任务。

它可以理解为：

```text
一个长期运行的小程序
```

例如：

```text
imu_task：读取 IMU
control_task：运行控制器
mavlink_task：处理通信
logger_task：记录数据
battery_task：检测电池
```

每个任务可以有自己的执行周期。

例如：

```text
IMU 读取：1000 Hz
姿态控制：250 Hz
位置控制：50 Hz
通信任务：50 Hz
日志任务：10 Hz
电池检测：5 Hz
```

一句话理解：

```text
Task = RTOS 中独立运行的功能模块。
```

---

## 6. Scheduler 调度器

Scheduler 是调度器。

它负责决定：

```text
哪个任务先运行
哪个任务后运行
哪个任务等待
哪个任务恢复
哪个任务优先级更高
```

例如在飞控中：

```text
控制任务优先级高
通信任务优先级中
日志任务优先级低
```

因为控制任务延迟太大会影响飞行稳定性，而日志任务稍微慢一点通常不会立刻导致坠机。

一句话理解：

```text
Scheduler = 决定任务运行顺序和运行时机的管理者。
```

## 7. Interrupt 中断

Interrupt 是中断。

中断可以理解为：

```text
硬件或定时事件突然提醒 CPU：有重要事情要马上处理。
```

常见中断包括：

```text
IMU 数据准备好了
串口收到数据
定时器到时间了
遥控器信号输入
DMA 传输完成
```

中断比普通任务更紧急。

例如：

```text
CPU 正在运行日志任务
突然串口收到 MAVLink 数据
触发串口中断
CPU 先处理接收数据
处理完再回到原来的任务
```

一句话理解：

```text
Interrupt = 硬件或定时事件触发的紧急处理机制。
```

## 8. STM32、FreeRTOS 和 PX4 的关系

真实飞控系统可以这样理解：

```text
传感器
    ↓
STM32 外设驱动
    ↓
PX4 驱动层
    ↓
uORB 消息
    ↓
EKF2 状态估计
    ↓
控制器
    ↓
电机输出
```

STM32 提供硬件运行平台。

FreeRTOS 或类似实时系统负责多任务调度。

PX4 在上面运行飞控算法、状态估计、控制器和通信模块。

## 10. 飞控中的实时性

飞控非常重视实时性。

例如：

```text
IMU 数据需要高频读取
角速度控制需要快速运行
电机输出需要及时更新
安全检查不能长时间阻塞
```

如果实时性不好，可能出现：

```text
姿态控制滞后
控制输出不稳定
传感器数据延迟
飞行抖动
严重时可能失控
```

因此嵌入式飞控通常需要实时系统支持。

## 11. 今日总结

今天理解了 STM32 和 FreeRTOS 的基础概念。

最重要的结论：

```text
STM32 是飞控板上的嵌入式控制芯片；
FreeRTOS 是管理多个实时任务的小型操作系统；
飞控需要实时读取传感器、运行控制器、输出电机信号；
实时性对无人机稳定飞行非常重要。
```

一句话总结：

```text
STM32 负责靠近硬件，FreeRTOS 负责任务调度，PX4 负责飞控逻辑。
```
